# Red_Empresarial_Pyme
Proyecto de diseño e implementación de una red empresarial para una PYME utilizando tecnologías Cisco.

Tecnologías utilizadas
- VLANs
- Router-on-a-Stick
- DHCP
- ACLs
- Port Security
- Trunking 802.1Q
- Parking Lot VLAN

Objetivos
Segmentar departamentos.
Asignar IP automáticamente.
Controlar acceso mediante ACLs.
Aplicar hardening básico de switches.

Resultados
 Comunicación entre VLANs.
 DHCP operativo.
 ACL funcional.
 Seguridad básica implementada.
